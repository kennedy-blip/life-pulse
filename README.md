# LifePulse

AI-powered personal operations hub. Built with React, Vite, Tailwind CSS and Lucide React.

## Getting started

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
```

Deploy the repository to Vercel with the Vite preset. Build command: `npm run build`; output directory: `dist`.

LifePulse stores demo workspace data in your browser using localStorage. Receipt parsing and route optimization are client-side simulations; no external AI or mapping API key is required.
